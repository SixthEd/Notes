An asynchronous task refers to an operation that can be executed without blocking the main thread of execution. This means that the program can continue to perform other operations while the asynchronous task is running in the background. Examples include network requests, file I/O, or database interactions. In JavaScript, asynchronous tasks are often handled using mechanisms like Promises or async/await.

In a Promise chain, only the first catch() that handles the error runs, unless it throws another error.


Promise.allSettle() always run if a promise fullfilled or not 

Yes, even if all promises fail, Promise.allSettled() still resolves and its .then() runs.
It waits for all promises to settle and then resolves with their statuses.


		const p1 = Promise.reject("Error 1");
		const p2 = Promise.reject("Error 2");
		const p3 = Promise.reject("Error 3");

		Promise.allSettled([p1, p2, p3])
		  .then(results => {
		    console.log("then runs");
		    console.log(results);
		  })
		  .catch(err => {
		    console.log("catch runs");
		  });

o/p:
		[
			  { status: "fulfilled", value: "Success" },
			  { status: "rejected", reason: "Failed" },
			  { status: "fulfilled", value: "Done" }
		]


Promise.all():

Promise.all() waits for all promises and returns their results in an array. If one of the promise is rejected then whole process is reject and return only reject one.

Promise.any() :

Promise.any() returns the first fulfilled (successful) Promise.
It ignores rejected promises unless all promises reject.

Promise.race() :
Promise.race() returns the result of the first Promise that settles.


  
Promise.all([])	Resolves with []
Promise.allSettled([])	Resolves with []
Promise.any([])	Rejects with AggregateError
Promise.race([])	Promise Pending forever
