React

UseState:
UseState is a React Hook that allows functional components to hold, update, and preserve data (state) across renders, triggering a re-render when the state changes.

UseEffect:
UseEffect is a React Hook used to perform side effects in function components after rendering.

UseCallback:
UseCallback returns the same function reference from the previous render as long as its dependencies don’t change, preventing unnecessary re-renders and effect executions.
 
Memo:
Memo lets you skip re-rendering a component when its props are unchanged.

UseMemo:
UseMemo is similar to useCallback, but instead of memoizing a function reference, it memoizes a computed value from the previous render and returns the cached value until its dependencies change.

UseRef:
useRef is a React Hook that lets you reference a value that’s not needed for rendering.

UseReducer:
UseReducer is a React Hook used for managing complex state logic using a reducer function.

UseTransition:
useTransition lets you mark some state updates as non-urgent, so React keeps the UI responsive while doing heavy work.

UseContext:
useContext lets a component read data from a Context that is provided by a parent component — without passing props through every level.

Controlled Component: 
A form element whose value is managed by React state and updated through React.

Uncontrolled Component: 
A form element whose value is managed by the DOM itself, and React accesses the value using refs when needed.

Lifting State Up
Lifting State Up is a pattern in React where you move the state from child components to a common parent component so that multiple child components can share and synchronize this state. 

Mount:
The moment a React component is created and inserted into the real DOM for the first time.

Virtual DOM:
The Virtual DOM (VDOM) is a lightweight JavaScript representation of the real DOM that React keeps in memory to decide what to change in the browser.










Javascript:

Execution Context:

Hositing:
Hoisting is the process that occurs during the creation phase of an execution context, where JavaScript creates identifier bindings for variables and declarations before code execution begins. For let, const, and class, the bindings are created (memory is set up), but they remain uninitialized until their declaration is executed.

Temporal Dead Zone:
The Temporal Dead Zone (TDZ) is the period between the creation of a let, const, or class binding and the execution of its declaration that initializes the binding.
	or
The TDZ is the period between entering a scope/block and the initialization of a let, const, or class binding. During this period, the binding exists but cannot be accessed; attempting to access it results in a ReferenceError.

CallBack functions:
function which is passed to another function as a argument

Closure:
A function that remembers variables from where it was created, even after that outer function has finished execution.

Asynchronous Task:
Asynchronous tasks are tasks that run independently without blocking the execution of the main program.

Promises:
A Promise is an object that represents the success or failure of an operation and its resulting value.

Async/Await:
async/await is syntax built on top of Promises that makes asynchronous code look like synchronous code.
