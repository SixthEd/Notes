Computers ultimately work with binary data (0s and 1s). A single 0 or 1 is called a bit, and 8 bits make 1 byte.

To represent text, computers use a character set. Today, the most common character set is Unicode, which assigns a unique code point to each character. For example, A is U+0041 and s is U+0073.

A character encoding such as UTF-8 converts these Unicode code points into one or more bytes. These bytes are stored in memory as binary data and can be transmitted over a network or saved to a file.

In Node.js, a Buffer is a fixed-size memory area used to store raw bytes. When data such as text, images, videos, files, or network packets is received, Node.js often stores the incoming bytes in a Buffer. The data can then be decoded or interpreted according to its format (UTF-8 text, JPEG image, MP4 video, JSON, etc.).
In Node.js, a Buffer primarily uses RAM (main memory), but more specifically, it is allocated outside the V8 JavaScript heap
