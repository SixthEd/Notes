Networking simply means way to communicate between the computers.

Networking layers:

Application layer: Data
Transport layer: Segment (TCP/UDP)
Network layer: This is where we have packets. This is where router comes into play and ip addresss.
Data Link Layer: This part moves data and frames. In data link we have switches, these switches will receive those zeros and ones and they will combines into this whole frame thing. So they will extract the mac address, the data, the destination mac address, the source mac address. they will create a combine it create neat concept called frame, and they will figure out which machine has the destination mac address and the frame across to that machine
Physical Layer: Ethernet cables that has RJ 45 connectors. (take bits)

TCP headers:

source port (16 bits), it is the port that the request is getting sent from.
Destination port (16 bits)
sequence number (32 bits)
acknowledge number (32 bits)
window (how big is the packet should be)
Finn (tells whether or not the request is finished
data (optional) like in 3 way handshake we do not need data

TCP headers + data = segments

UDP headers: 64 bits or 8 bytes
source port (16 bits), it is the port that the request is getting sent from.
Destination port (16 bits)
segment length (tells how much big is the segment 16 bits) 
data
checksum (16 bits) it indicate whether data is or not corrupted
